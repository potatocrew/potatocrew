<h3 align="center">Learning something new every day.</h3>

I'm a data analyst who spends most of the day in Pandas and DuckDB, building ETL pipelines that turn messy operational data into something decisions can be made from. Lately I've been moving more of my workflows off Jupyter and into proper scripts, and I care a lot about making data transformations reproducible and easy to audit. The fun part for me is the engineering behind the analytics — getting data clean, typed, and flowing reliably.

#### What I'm up to

- 🔭 Replacing Jupyter notebooks with scheduled DuckDB pipelines for monthly reporting.
- currently deep in analytics
- probably overthinking a database schema right now
- rewrites it once, then leaves it alone
